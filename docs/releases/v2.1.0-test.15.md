# Finance Assist 2.1.0-test.15 — instaladores verificados e macOS

Data: 28 de setembro de 2026. Versão de teste.

## Motivo da revisão

A test.14 teve os instaladores Linux aprovados nos jobs de instalação, mas o
workflow geral terminou vermelho porque dois runners da suíte monolítica foram
interrompidos ou permaneceram ativos após 74%. A variante Noble publicada também
não veio do workflow Ubuntu 24.04 separado.

## Solução

- A suíte Linux foi dividida em dois grupos independentes, evitando estouro de
  tempo e preservando todos os 290 testes.
- O workflow Noble agora é acionado pela tag, compila efetivamente no Ubuntu
  24.04 e só gera o DEB depois que os dois grupos de testes passam.
- A instalação Noble valida checksum, dependências, Views, OCR, banco novo e
  atualização com banco sentinela preservado.
- Foram adicionados aplicativos macOS separados para Intel x64 e Apple Silicon
  arm64, ambos com autoteste de todas as Views e checksum SHA-256.
- O pacote macOS é uma versão de teste sem assinatura Apple. Na primeira
  abertura, o usuário pode precisar autorizar o aplicativo em Privacidade e
  Segurança nas Configurações do Sistema.

## Preservação de dados

Os instaladores não contêm banco, backup, configurações pessoais ou credenciais.
Os testes de atualização usam bancos sentinela temporários e confirmam que dados
existentes continuam preservados.
