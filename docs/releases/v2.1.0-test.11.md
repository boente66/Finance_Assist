# Finance Assist 2.1.0-test.11 — faturas visíveis e orçamento mensal

Data: 20 de setembro de 2026.

## Correções

- A tabela de uma fatura mantém altura útil mesmo quando existem muitas faturas
  futuras, permitindo consultar todas as compras de faturas pagas.
- A paginação volta automaticamente para uma página válida quando o usuário
  troca de cartão ou competência.
- O histórico financeiro permanece intacto: esta atualização não remove nem
  recria bancos, faturas, compras ou pagamentos existentes.

## Planejamento

- Agendamentos mostra o mês atual e os três meses seguintes em botões visíveis.
- Um clique troca a competência imediatamente usando os dados já carregados.
- A tabela exibe apenas agendamentos e vencimentos do mês escolhido.
- Receitas, agendamentos a pagar, faturas, total e resultado são recalculados
  para a competência selecionada.
