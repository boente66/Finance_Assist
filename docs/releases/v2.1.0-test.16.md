# Finance Assist 2.1.0-test.16 — pagamentos flexíveis de fatura

Data: 3 de outubro de 2026. Versão de teste.

## Alterações

- pagamento antecipado em fatura aberta;
- pagamento parcial com saldo restante visível;
- pagamento total com mudança para `PAGA` somente após a quitação de uma fatura
  fechada;
- vários pagamentos registrados separadamente em `pagamentos_fatura`;
- saída real na conta e recomposição do limite pelo valor efetivamente pago;
- novas compras continuam entrando na fatura aberta depois de uma antecipação;
- bloqueio de valor zero, negativo ou superior ao saldo pendente;
- interface permite escolher conta e valor do pagamento;
- banco e migrations permanecem compatíveis, sem alteração de schema.

## Validação

- antecipação em fatura aberta;
- compra nova depois da antecipação;
- pagamento parcial e quitação posterior;
- débito da conta, recomposição do limite e histórico de pagamentos;
- rejeição de pagamento acima do saldo;
- interface usando o saldo oficial do `FaturaService`;
- atomicidade e compatibilidade com o ciclo existente.

Os instaladores são gerados pelo GitHub Actions para Ubuntu, Windows e macOS. O
workflow separado do Ubuntu 24.04/Mint 22.x instala e valida o pacote antes da
publicação. Bancos existentes são preservados durante a atualização.
