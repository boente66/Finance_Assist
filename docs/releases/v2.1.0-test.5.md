# Finance Assist 2.1.0-test.5 — correção das telas empacotadas

Versão de teste para Linux e Windows.

- Corrige a omissão de views carregadas dinamicamente, incluindo Resumo Financeiro.
- Enumera as views pelo diretório do projeto, independentemente do caminho de execução do PyInstaller.
- Testa importação, construção e renderização das telas dentro do executável com banco temporário.
- Inclui as dependências de tradução e categorização antes excluídas do build.
- Declara Poppler, Tesseract e o idioma português como dependências do DEB para OCR.
- Completa as bibliotecas XCB necessárias à execução gráfica no Ubuntu.
- Isola as bibliotecas do executável das ferramentas externas de OCR, corrigindo a execução em versões novas do Ubuntu.
- Uniformiza as DLLs redistribuíveis MSVC no pacote Windows para carregar o ONNX Runtime.
- Grava o log no diretório de dados gravável do aplicativo.

O DEB é compilado no Ubuntu 22.04 e validado também no Ubuntu 24.04 e 26.04.
O ZIP Windows é portável. OCR no Windows requer Tesseract com idioma português e
Poppler disponíveis no PATH; esses programas externos não fazem parte do ZIP.
Modelos de tradução e categorização requerem download na primeira utilização.

## Instalação

Linux: baixe o DEB e seu checksum nesta release e execute:

```bash
sha256sum -c finance-assist_2.1.0-test.5_amd64.deb.sha256
sudo apt install ./finance-assist_2.1.0-test.5_amd64.deb
finance-assist-test
```

Windows: baixe o ZIP e seu checksum, compare o SHA256 com `Get-FileHash`,
extraia o ZIP em uma pasta e execute `FinanceAssist-test.exe`.

Atualizações mantêm o banco existente. Os testes do pacote usam armazenamento
temporário separado dos dados pessoais.
