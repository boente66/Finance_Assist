# Finance Assist 2.1.0-test.2 — teste multiplataforma

Esta versão de teste normaliza a escala visual do aplicativo e inaugura a geração
automatizada de artefatos para Ubuntu e Windows. Não é uma versão estável de
produção.

## Destaques

- tipografia, campos, botões, tabelas, cards e perfil com proporções mais
  equilibradas;
- editor de temas impedido de gerar métricas que comprometam a área útil;
- login adaptativo, removendo primeiro elementos decorativos em telas compactas;
- seletor de intervalo de datas empilhável;
- diálogo de criação de conta redimensionável e centralizado;
- DEB `amd64` compilado no Ubuntu 22.04 LTS;
- ZIP portátil `x64` compilado para Windows;
- checksums SHA-256 publicados junto dos dois pacotes;
- workflow reproduzível em `.github/workflows/build-multiplatform.yml`.

## Sistemas-alvo

| Plataforma | Situação |
|---|---|
| Ubuntu 22.04 LTS `amd64` | ambiente-base do pacote DEB |
| Ubuntu posterior `amd64` | alvo de compatibilidade; requer homologação local |
| Windows 11 `x64` | alvo do pacote portátil |
| Windows 10 `x64` | sem suporte oficial do sistema desde 14/10/2025; não homologado |
| macOS | sem artefato nesta versão |

## Segurança dos artefatos

Os scripts instalam ou arquivam somente o executável, ícone, licença, README e
metadados necessários. Banco financeiro, configuração local, backups, logs,
caches e ambiente virtual não fazem parte dos pacotes.

## Evidências de validação

- 169 testes de integração aprovados;
- 195 testes aprovados na suíte completa;
- 42 testes focais de escala, login, responsividade e empacotamento aprovados;
- compilação de sintaxe e `git diff --check` aprovados;
- DEB gerado localmente, checksum validado e conteúdo inspecionado;
- executável Linux iniciado por 15 segundos em Qt offscreen sem encerramento
  inesperado (finalização deliberada pelo limite de tempo);
- bundle confirmado sem pytest, banco, backup, log, cache ou ambiente virtual.

O artefato Windows é validado no runner Windows Server 2022 do GitHub Actions;
o resultado desse job deve estar aprovado antes da publicação da release.

## Limitações

- versão destinada a teste e homologação;
- diferenças de DPI, tema nativo e ambiente gráfico podem alterar a renderização;
- o ZIP do Windows não é um instalador e pode acionar avisos de reputação do
  SmartScreen por não possuir assinatura de código;
- a licença do projeto restringe uso comercial sem autorização escrita.
