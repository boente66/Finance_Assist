# Finance Assist 2.1.0-test.4 — instalação validada em Ubuntu LTS

Esta versão corrige o isolamento do banco de desenvolvimento e valida o pacote
Debian real nas três versões Ubuntu LTS suportadas.

## Correções

- removida toda clonagem implícita do `financeiro.db` da raiz;
- desenvolvimento novo inicia com banco vazio criado pelo schema e migrations;
- banco instalado existente permanece em `~/.financeassist/financeiro.db`;
- dependência Debian aceita `libglib2.0-0 | libglib2.0-0t64`;
- um único DEB é compilado no Ubuntu 22.04 e instalado com `apt` em Ubuntu
  22.04, 24.04 e 26.04;
- cada instalação usa HOME limpa, inicia o executável e verifica o SQLite;
- um banco criado antes da instalação é reaberto, migrado e preservado;
- um banco-sentinela no checkout confirma que dados de desenvolvimento não são
  incorporados nem copiados pelo pacote;
- ZIP Windows e checksum continuam gerados em ambiente Windows limpo.

## Critério de aprovação

A release só deve ser publicada após todos os jobs de código, instalação do DEB
e pacote Windows terminarem com sucesso. Esta permanece uma versão de teste.
