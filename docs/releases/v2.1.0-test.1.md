# Finance Assist 2.1.0-test.1 — teste para Linux

Esta é uma versão **de teste**, destinada à validação inicial do Finance Assist
em distribuições Linux compatíveis com pacotes Debian (`amd64`). Não é uma
versão estável de produção.

## Destaques

- tela **Meu Perfil** modernizada conforme o padrão visual do aplicativo;
- edição segura dos próprios dados, sem possibilidade de alterar o nível de acesso;
- preferências de tema e idioma integradas aos contratos existentes;
- alteração de senha com confirmação da senha atual;
- layout responsivo com rolagem em resoluções reduzidas;
- barra lateral atualizada imediatamente após alteração do nome ou e-mail;
- versão centralizada e exibida no rodapé do perfil.

## Instalação

```bash
sudo apt install ./finance-assist_2.1.0-test.1_amd64.deb
```

Após a instalação, procure por **Finance Assist (Teste)** no menu de aplicativos
ou execute:

```bash
finance-assist-test
```

## Verificação

Compare o arquivo baixado com o checksum publicado:

```bash
sha256sum -c finance-assist_2.1.0-test.1_amd64.deb.sha256
```

## Avisos

- faça backup dos dados antes de testar;
- o pacote foi preparado para arquitetura `amd64`;
- comportamentos podem variar entre distribuições e ambientes gráficos;
- reporte problemas pelo GitHub informando distribuição, versão e ambiente gráfico;
- o uso permanece sujeito à licença não comercial presente no repositório.

## Validação desta compilação

- 11 testes focais aprovados;
- sintaxe Python e script de build validados;
- pacote e checksum inspecionados;
- nenhum banco, backup, log, cache ou ambiente virtual incluído;
- inicialização do executável validada durante 12 segundos em Qt offscreen.

A suíte integral foi interrompida antes do resumo final. Este fato, somado à
necessidade de validação em diferentes distribuições e ambientes gráficos,
justifica a classificação explícita desta entrega como **versão de teste**.
