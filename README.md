💰 Sistema de Controle Financeiro

Sistema desktop desenvolvido em Python com PyQt para gerenciamento financeiro completo, com arquitetura modular e recursos avançados.

---

🚀 Visão Geral

O sistema permite o controle completo de finanças pessoais ou operacionais, incluindo contas, cartões de crédito, transações e planejamento financeiro.

Projetado com foco em:

- organização financeira
- performance
- interface moderna
- escalabilidade

---

⚙️ Funcionalidades

- 📊 Controle de contas bancárias
- 💳 Gestão de cartões de crédito
- 🔁 Transferência entre contas
- 📥 Importação inteligente de extratos
- 📤 Exportação de dados (CSV, XLSX, PDF)
- 🎯 Metas financeiras
- 📅 Agendamentos financeiros
- 🎨 Tema claro/escuro
- 🧩 Arquitetura modular (MVC)

---

🖥️ Tecnologias

- Python
- PyQt5
- SQLite
- SVG Icons

---

📦 Instalação

O sistema será disponibilizado através da aba Releases do GitHub.

Plataformas suportadas:

- Windows (.exe)
- Linux (.deb / AppImage)
- macOS (.dmg)

### Teste para Linux

A versão **2.1.0-test.1** está sendo disponibilizada como teste inicial para
Linux `amd64` em pacote Debian. Ela não é classificada como versão estável.

Consulte as [notas da versão de teste](docs/releases/v2.1.0-test.1.md) antes de
instalar e faça backup dos dados. O pacote e seu checksum são publicados nos
Releases do GitHub.
