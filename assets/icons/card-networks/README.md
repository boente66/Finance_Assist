# Identificação visual de bandeiras

Arte SVG preservada de [svg-credit-card-payment-icons](https://github.com/aaronfagan/svg-credit-card-payment-icons),
por Aaron Fagan e contribuidores, sob Apache-2.0. A revisão exata, URLs e SHA256
estão em [SOURCE.json](./SOURCE.json); a licença integral em [LICENSE](./LICENSE).

Os direitos sobre marcas permanecem com os titulares. A licença dos arquivos
não concede direitos gerais sobre marcas (seção 6). Uso apenas identificador
de metadado escolhido pelo usuário; sem afiliação, aceitação de pagamentos ou
endosso. Homologação visual e adequação de marcas precedem distribuição.

Visa, Mastercard, Elo, American Express, Hipercard, Diners Club, Discover, JCB,
UnionPay e Maestro têm representação comercial disponível nessa coleção.
Sem bandeira usa generic.svg. Cabal, Banescard, Aura e Sorocred também usam o
cartão genérico acompanhado do nome comercial: não foi inventado um logotipo
nem incluído recurso sem fonte/licença verificada. Esta limitação é explícita
na entrega para homologação; substituir por arte identificadora autorizada
quando fornecida/validada, sem necessidade de alterar os dados do cartão.

Os arquivos acompanham assets nos specs de empacotamento existentes; nenhum
download ocorre em tempo de execução. Texto continua disponível se ícone falhar.

Alguns arquivos tiveram somente finais de linha CRLF normalizados para LF.
SOURCE.json conserva hash original e hash local quando diferentes; a arte não foi alterada.
